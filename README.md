# PoseSlide

> 클릭 없이, 손짓 하나로 넘기는 프레젠테이션.

**PoseSlide**는 웹캠으로 인식한 손 제스처로 PDF 프레젠테이션을 넘길 수 있는 도구입니다. 발표자가 원하는 손모양을 직접 "다음/이전 페이지" 제스처로 등록할 수 있고, 발표자 전용 컨트롤러 화면과 청중에게 보여줄 클린 화면을 분리해 실제 발표 환경에서 바로 사용할 수 있도록 만들었습니다.

## 📌 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 종류 | 손 제스처 기반 PDF 프레젠테이션 컨트롤러 |
| 플랫폼 | 데스크톱 (Windows / macOS) |
| 개발 기간 | 1주 |
| 팀 구성 | 1인 |

발표 중 리모컨이나 키보드 없이, 웹캠 앞에서 손짓만으로 슬라이드를 넘길 수 있게 만든 개인 프로젝트입니다. 발표자는 별도의 컨트롤러 창에서 웹캠 미리보기와 제스처 상태를 확인하고, 청중에게는 PDF만 깨끗하게 보이는 화면을 프로젝터로 띄우는 구조입니다.

## ⚙️ 주요 기능

**실시간 손 제스처 인식**
OpenCV로 웹캠 프레임을 받아 MediaPipe Hands로 21개 손 랜드마크를 추출하고, 각 손가락 끝과 관절이 손목으로부터 얼마나 떨어져 있는지 비교해 5개 손가락 각각의 펴짐/접힘 상태를 실시간으로 판별하는 로직을 직접 구현했습니다. 인식 루프는 별도 `QThread`에서 돌려 UI가 멈추지 않도록 했습니다.

**사용자 정의 제스처 등록**
정해진 제스처를 강요하지 않고, "다음 페이지 설정" / "이전 페이지 설정" 버튼을 누른 뒤 2초간 원하는 손모양을 유지하면 그 손가락 패턴을 해당 동작으로 저장하는 커스텀 제스처 등록 기능을 만들었습니다. 발표자가 자신에게 편한 손모양을 자유롭게 지정할 수 있습니다.

**발표자용 컨트롤러 / 청중용 클린 화면 분리**
PyQt5로 두 개의 독립된 창을 구성했습니다 — 청중에게 보여줄 `SlideWindow`(PDF만 표시되는 클린 화면)와, 발표자만 보는 `ControllerWindow`(웹캠 미리보기, 인식 상태, 제스처 설정 UI). 두 창은 PyQt Signal/Slot으로 연결되어, 컨트롤러 창에서 인식된 제스처가 메인 슬라이드 창의 페이지 전환으로 바로 이어집니다.

**PDF 렌더링 & 캐싱**
PyMuPDF로 PDF 페이지를 고해상도 이미지로 렌더링하고, 한 번 렌더링한 페이지는 캐싱해 재방문 시 즉시 표시되도록 해 페이지 전환 시 버벅임을 없앴습니다.

**오작동 방지 쿨다운**
제스처가 인식되어 페이지가 전환된 직후 1.5초간 쿨다운을 걸어, 같은 손모양이 유지되는 동안 페이지가 연속으로 넘어가는 오작동을 방지했습니다.

**발표 최적화 전체화면 모드**
F11로 툴바와 상태바를 숨기고 전체화면으로 전환, ESC로 다시 창모드로 복귀할 수 있도록 구현했습니다.

## ▶️ 실행 방법

```bash
pip install PyQt5 opencv-python mediapipe PyMuPDF
python main.py
```

실행 후 `Ctrl+O`로 PDF를 열고, 컨트롤러 창에서 원하는 손모양으로 다음/이전 페이지 제스처를 등록하면 됩니다.
